# Ambientes desenvolvimento de software

## Funcionamento da aplicação

A aplicação consiste em um **site web desenvolvido para apresentar e executar diferentes algoritmos de programação**, permitindo ao usuário escolher entre duas linguagens de programação: **Java** e **JavaScript**.

Ao acessar a aplicação, o usuário poderá selecionar uma das linguagens disponíveis. Após realizar a escolha, o sistema apresentará uma lista de algoritmos que podem ser selecionados e executados.

O objetivo da aplicação é proporcionar uma forma simples e interativa de visualizar o funcionamento de diferentes algoritmos implementados em **Java** e **JavaScript**.

## 🖥️ Fluxo da aplicação

O funcionamento do sistema segue as seguintes etapas:

1. O usuário acessa o site;
2. O sistema apresenta as opções de linguagens de programação;
3. O usuário escolhe entre **Java** ou **JavaScript**;
4. Após selecionar a linguagem, o sistema apresenta os algoritmos disponíveis;
5. O usuário escolhe um dos algoritmos;
6. A aplicação executa o algoritmo selecionado;
7. O resultado da execução é apresentado ao usuário.

## 💻 Linguagens disponíveis

A aplicação possui duas opções de linguagem:

### ☕ Java

O usuário pode selecionar **Java** para visualizar e executar os algoritmos desenvolvidos nessa linguagem.

### 🟨 JavaScript

Também é possível selecionar **JavaScript**, permitindo executar os mesmos tipos de algoritmos utilizando uma implementação nessa linguagem.

## 🧮 Algoritmos disponíveis

Após escolher a linguagem, o usuário poderá selecionar entre os seguintes algoritmos:

### 1. Is Even

Verifica se um determinado número é **par ou ímpar**.

O algoritmo recebe um número como entrada e verifica se ele pode ser dividido por 2 sem deixar resto.

**Exemplo:**

```text
Entrada: 10
Saída: Even
```

---

### 2. Summation

Realiza a **soma dos valores** de acordo com os dados fornecidos pelo usuário.

O algoritmo pode ser utilizado para demonstrar operações de acumulação e processamento de valores.

**Exemplo:**

```text
Entrada: 1 2 3 4 5
Saída: 15
```

---

### 3. Sorting

Realiza a **ordenação de valores**, organizando os elementos de acordo com uma determinada ordem.

**Exemplo:**

```text
Entrada:
5 2 8 1 3

Saída:
1 2 3 5 8
```

Esse algoritmo demonstra conceitos importantes relacionados à organização e manipulação de dados.

---

### 4. Fibonacci

Calcula a sequência de **Fibonacci**, na qual cada número é obtido pela soma dos dois números anteriores.

**Exemplo:**

```text
Entrada: 7

Saída:
0 1 1 2 3 5 8
```

O algoritmo permite demonstrar conceitos de repetição e, dependendo da implementação, recursividade.

---

### 5. Greatest Common Divisor

Também conhecido como **GCD (Greatest Common Divisor)**, calcula o **maior divisor comum** entre dois números.

Por exemplo:

```text
Entrada:
12 18

Saída:
6
```

O algoritmo pode ser utilizado para demonstrar operações matemáticas e o algoritmo de Euclides.

---

### 6. Count

Realiza uma **contagem de elementos ou valores** de acordo com os parâmetros fornecidos pelo usuário.

Esse algoritmo demonstra o uso de estruturas de repetição e variáveis de controle para realizar contagens.

## 🎯 Objetivos do projeto

A aplicação foi desenvolvida com os seguintes objetivos:

* Demonstrar a implementação de algoritmos em diferentes linguagens;
* Permitir a comparação entre **Java** e **JavaScript**;
* Facilitar a visualização do funcionamento dos algoritmos;
* Praticar conceitos de desenvolvimento de software;
* Aplicar conceitos de lógica de programação;
* Criar uma interface web para interação com os algoritmos.
